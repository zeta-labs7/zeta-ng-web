# ZL Ticketing

A lightweight DevOps service desk for application onboarding, AWS provisioning,
CI/CD support, and access requests. The sample dashboard includes ticket
search and status filters, summary metrics, ticket details, and a create-ticket
form. Ticket data is held in memory and resets when the page is refreshed.

## Requirements

- Node.js 26 or later
- npm 11 or later

## Run locally

```bash
npm install
npm start
```

Open `http://localhost:4200/` in a browser.

## Build

```bash
npm run build
```

This project uses Angular 22.
